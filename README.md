# Birthday Card

Thiệp sinh nhật tương tác theo phong cách vintage scrapbook, gồm trang mở đầu, menu ba bất ngờ, lá thư, bó hoa và bánh sinh nhật.

## Chạy dự án

```bash
npm install
npm run dev
```

Mở `http://127.0.0.1:5173/`.

## Kiểm tra

```bash
npm run lint
npm run build
npm run test:e2e
```

Nội dung lời chúc, nhãn điều hướng và các ghi chú trên hoa nằm trong `src/App.tsx`. Giao diện và chuyển động nằm trong `src/App.css`; ảnh minh họa nằm trong `src/assets`.
